# DSI Wiki Provenance

## Usage

```
DSI-wiki-provenance [--instance Cain-the-elder] [--topic <topic_filter>] "<claim string>"
```

Examples:
```
DSI-wiki-provenance "qwen2.5-coder"
DSI-wiki-provenance --instance Cain-the-elder --topic MAIN_DSI-LLM-ROUTER "port 9124"
```

Output: one line per hit — `<layer>/<topic>.md | <line_no> | <mtime> | <matching line excerpt>`.
Exit 0 with hits, exit 1 when no match found.

- Host-side wrapper (Docker path): `~/.local/bin/DSI-wiki-provenance` (proxies into the
  `gateway` container, generated by `TOOLS/install-cli-proxies.sh`, do not hand-edit)
