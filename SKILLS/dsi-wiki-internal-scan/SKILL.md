# DSI-Wiki Internal Consistency Scanner

## Usage

```
DSI-wiki-internal-scan --topic MAIN_DSI-LLM-ROUTER
DSI-wiki-internal-scan --instance Cain-the-elder --all
```

- Compares factual claims (model names, paths, ports, commands, statuses) between the
  documentation and minified layers of each topic.
- Report output (append mode): `/BIG/PROJECTS/DSI/DSI-WIKI/reports/internal-scan-YYYYMMDD.md`
- Stdout: `<topic>: <verdict first 80 chars>` per topic.
- Exit codes: 0 = consistent, 2 = bad args/instance, 3 = drift detected, 4 = Ollama unreachable.
- Ollama calls serialized (one at a time, VRAM queue), model: `qwen3:1.7b` (switched from
  Bonsai-27B 2026-07-30 — too slow on this host's 8GB GTX 1070 for CPU-offloaded generation),
  `POST /api/chat` with `stream:false, think:false`, timeout 600s.

## Files
- Source: `/BIG/PROJECTS/DSI/DSI-WIKI/SKILLS/cli/internal_scan.py`
- Host-side wrapper (Docker path): `~/.local/bin/DSI-wiki-internal-scan` (proxies into the
  `gateway` container, generated by `TOOLS/install-cli-proxies.sh`, do not hand-edit)
